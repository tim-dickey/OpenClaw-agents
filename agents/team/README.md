# Team Agents

Team agents are designed for group collaboration — Daily Scrum, Sprint management, impediment tracking, and team communication.

## Available Agents

| Agent | Name | Description |
| --- | --- | --- |
| [scrum-master-coach](./scrum-master-coach/) | Velocity | Scrum Master \| Coach — Daily Scrum, Sprint tracking, impediments, and team summaries |

## Adding a Team Agent

Copy the template from [`agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full guidelines.
