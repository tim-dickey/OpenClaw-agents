# Developer Agents

Developer agents are built for software engineering workflows — code review, debugging, documentation lookup, and GitHub integration.

## Available Agents

| Agent | Name | Description |
| --- | --- | --- |
| [code-reviewer](./code-reviewer/) | Hex | Code reviewer — bugs, style, security analysis with GitHub integration |

## Adding a Developer Agent

Copy the template from [`agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full guidelines.
