# Creative Agents

Creative agents assist with writing, content creation, storytelling, and brand voice development.

## Available Agents

| Agent | Name | Description |
| --- | --- | --- |
| [content-writer](./content-writer/) | Lyra | Content writer — blog posts, social media, newsletters, and creative copy |

## Adding a Creative Agent

Copy the template from [`agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full guidelines.
