# Agents

This directory contains all agent personas available in the OpenClaw Agent Project. Agents are fully defined AI personas that you load into OpenClaw to give your assistant a specific role, personality, and set of capabilities.

![Agent Team](../Agent%20team.png)

## Categories

| Category | Description |
| --- | --- |
| [personal/](./personal/) | Agents for personal productivity, daily routines, and life management |
| [professional/](./professional/) | Workplace agents for executive assistants, project managers, and more |
| [developer/](./developer/) | Agents tailored for software development workflows |
| [creative/](./creative/) | Agents for writing, content creation, and brainstorming |
| [team/](./team/) | Agents designed for team collaboration and coordination |

## How to Use an Agent

1. Browse the category folders above to find an agent that fits your needs
2. Open the agent folder and read its `README.md` for details
3. Copy the `agent.md` file to your OpenClaw agents directory
4. Customize the file as needed (see [`docs/customization-guide.md`](../docs/customization-guide.md))
5. Restart or hot-reload OpenClaw and engage via your chosen chat channel
