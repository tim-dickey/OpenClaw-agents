# Personal Agents

Personal agents help you manage your daily life — routines, schedules, information digests, and personal productivity.

## Available Agents

| Agent | Name | Description |
| --- | --- | --- |
| [daily-briefing](./daily-briefing/) | Aria | Morning briefing agent — calendar, weather, top news, and pending tasks |

## Adding a Personal Agent

Copy the template from [`agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full guidelines.
