# Testing Guide

This document serves as the testing guide for this project, capturing test-related notes and guidelines.

- Use this file to record high-level or exploratory manual test notes that are not yet covered by automated tests.
- Summarize important test cases and expected outcomes.
- Capture any known issues or edge cases discovered during testing.
- For executable and automated tests (including pytest stub/live modes) and the distinction between `tests/` and `evals/`, see [tests/README.md](./tests/README.md). Do not duplicate those test cases here; instead, reference them or record only additional manual context.
