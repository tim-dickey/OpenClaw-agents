# Code of Conduct

## Our Pledge

This project is open to contributors of all skill levels. We are committed to
maintaining a welcoming environment where everyone can participate, ask questions,
and contribute constructively.

## Expected Behavior

- Be kind, constructive, and helpful in all interactions.
- Give and receive feedback graciously — review comments should improve the work,
  not diminish the person.
- Assume good intent. If a message reads as ambiguous, ask rather than assume.
- Welcome contributors who are new to the project or the domain.

## Unacceptable Behavior

The following will not be tolerated in any project space (issues, pull requests,
discussions, commit messages, or any other communication channel):

- Harassment, intimidation, or personal attacks of any kind.
- Hate speech or discriminatory language related to age, disability, ethnicity,
  gender identity, nationality, race, religion, sexual orientation, or any other
  protected characteristic.
- Deliberate disruption of discussions or code review.
- Publishing others' private information without explicit permission.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code of conduct.
Reports of unacceptable behavior may result in a warning, temporary suspension,
or permanent removal from the project at the maintainers' discretion.

## Reporting

If you experience or witness behavior that violates this code of conduct, open a
private GitHub Security Advisory (via the **Security** tab) or contact the
maintainer directly through the repository profile. All reports will be reviewed
promptly and handled with discretion.

## Questions?

Open an issue or start a discussion. We are glad you are here.
