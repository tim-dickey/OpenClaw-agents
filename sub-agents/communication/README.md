# Communication Sub-Agents

Communication sub-agents handle email, messaging, and notification tasks — composing, triaging, and managing outgoing and incoming communications.

## Available Sub-Agents

| Sub-Agent | Description |
| --- | --- |
| [email-manager](./email-manager/) | Triages incoming emails and drafts structured responses |

## Use Cases

Communication sub-agents are ideal when a parent agent needs to:

- Process and prioritize an email inbox
- Draft replies in the user's voice
- Send notifications or follow-up messages
- Route messages to the right person or channel

## Adding a Communication Sub-Agent

Copy the template from [`sub-agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidelines.
