# Productivity Sub-Agents

Productivity sub-agents manage tasks, project commitments, and schedules on behalf of parent agents or users.

## Available Sub-Agents

| Sub-Agent | Description |
| --- | --- |
| [task-tracker](./task-tracker/) | Captures, categorizes, and updates tasks; returns a structured task list |

## Use Cases

Productivity sub-agents are ideal when a parent agent needs to:

- Capture action items from a conversation or meeting
- Update task status based on user input
- Generate a structured task list for review
- Flag overdue or at-risk tasks

## Adding a Productivity Sub-Agent

Copy the template from [`sub-agents/_template/`](../_template/), place it in a new kebab-case folder here, and fill in all fields. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidelines.
